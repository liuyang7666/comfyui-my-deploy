# 分辨率选择

ComfyUI 自定义图像缩放节点。搜索「分辨率选择」，或在 image/upscaling 分类中添加。

输入 IMAGE 和分辨率下拉选项，输出 IMAGE、实际宽度、实际高度。支持放大、缩小和图像批次，无新增依赖，不调用生成模型。

| 选项 | 输出长边像素 |
| --- | ---: |
| 1K | 1024 |
| 2K | 2048 |
| 4K | 4096 |
| 6K | 6144 |
| 8K | 8192 |
| 12K | 12288 |

短边按原比例换算后四舍五入到最近的16倍数，最小16。不裁剪、不补边。长边固定、宽高均为16倍数与任意原比例不能始终精确兼得，因此短边通常最多偏离理想值8像素；极细长图受最小16像素限制。

例：6000×4000 选择4K → 4096×2736；4000×6000 → 2736×4096；16:9图选择4K → 4096×2304。

采用浮点双三次抗锯齿缩放；已符合目标尺寸时直接返回输入。将本目录放到当前实例的 custom_nodes 中，重启 ComfyUI 后端，再刷新页面。
