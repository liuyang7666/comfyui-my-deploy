# Darkroom 蒙版内颜色匹配 v0.5.0

输入仍为图像、参考图、0–100强度，输出一个图像。0原样直通，100完整颜色调整。

肤色、天空、植物、水面、建筑：先用对应语义蒙版限定范围，再在其中选择连续颜色范围调整。颜色范围由原图可靠内区的多个颜色群自动建立；相同颜色在蒙版外不受该项调整。人物衣物不会因肤色调整而一起染色。

保留原图每个像素的线性sRGB亮度Y。取消参考曝光迁移、全局压暗曲线和旧人物曝光压缩。最终色域约束仍围绕原始Y投影，避免改色后再次压暗；不做锐化、降噪或原图缩放。

草、树、其他植物保留独立内区样本，使用共同的多颜色群方案作用于植物蒙版并集，避免仅因草/灌木名称不同而漏调。不是将所有植物压成一个平均色。肤色按参考颜色方向调整，保留原始明暗深浅，不再固定回原图色相。

参考缺少某类时，仅在两图均有足够人物内中性色证据时应用有界冷暖方向；否则该类不改色，并在日志中说明。不会把参考草色直接套给缺失的天空。

不压暗优先：原图已经接近纯白的天空无法在保持亮度的同时获得很深的颜色；色域不足时减少色度。参考中的低曝光风格不复制。

首次升级需为每张图补存肤色、天空、植物等应用蒙版，旧缓存只有人物/天空，不能伪造缺失蒙版。之后换参考、换强度及重复运行复用检测、蒙版和统计；所有文字检测共享一次SAM3图像编码。只使用已安装本地权重。
