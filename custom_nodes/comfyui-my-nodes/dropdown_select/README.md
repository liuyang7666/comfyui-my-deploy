# 下拉选择 v1.0.0

MY / 文本，节点 ID 为 `MYDropdownSelect`。下拉只显示短标题，唯一的 STRING 输出为选中标题对应的完整文本。

- 点击“添加”，在弹窗中填写标题和多行文本，保存后自动选中新项。
- 选中已有标题后点击“修改”，可以改名和编辑正文；取消或 Esc 不保存。
- 标题不能为空或重复；正文允许为空，不截断、不去除正文首尾空白，不解析通配符。
- Ctrl+Enter / Command+Enter 保存。选项存进工作流，保存、重新打开或复制节点后保留；不同节点独立。
- 空节点输出空字符串；损坏的选项数据或不存在的选中标题报出中文错误。

集成到 MY 时，将 `nodes.py`、`__init__.py` 放入 `dropdown_select/`，前端 `dropdown_select.js` 放入 MY 的 `web/`，再合并节点映射。使用 ComfyUI V3 API；无额外依赖或联网请求。
