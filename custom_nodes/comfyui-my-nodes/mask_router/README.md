# 遮罩分流（宽度）v1.0.0

MY / 遮罩处理，节点 ID：`MYMaskWidthRouter`。输入遮罩和像素阈值（默认32）；依次输出大遮罩、小遮罩。小遮罩可接 LaMa，大遮罩可接重绘。

每张遮罩按8连通区域分别判断，使用最粗处的局部厚度（近似最大内切圆直径），不使用面积、长度或外接框短边来判定大小。大于阈值整块进入大遮罩，等于或小于阈值进入小遮罩。3像素宽的直线在阈值3时进入小遮罩，即使很长；弯曲细线、细圆环也按厚度判断。

支持单张 `[H,W]`、标准 `[B,H,W]` MASK批次以及同尺寸MASK列表。列表按顺序拼成批次。两个输出保留相同画布、批次数量、顺序、dtype和device；没有该类别的帧输出全黑，不删除批次位置。两路之和精确还原输入，两路互不重叠。输出不膨胀、不羽化、不二值化。

几何测量使用原遮罩中灰度≥0.5的核心；独立区域若全部低于0.5，使用其非零范围。区域归属按非零像素连通，保留全部原灰度和软边。非零羽化尾巴相连时视为一个区域；不同对象需要独立判断时，上游应输出独立MASK批次。连接在粗块上的细枝会随整块进入大遮罩，不把同一连通对象切碎。

使用2倍最近邻栅格的精确欧氏距离变换，避免普通`2×像素中心距离`将3像素细线读成4像素。斜线、曲线和交叉点仍存在栅格误差；交叉点变粗也计入最粗处。分块计算含阈值半径的重叠范围，不缩小源遮罩。依赖现有numpy、torch、opencv-python和ComfyUI V3 API，无模型推理或联网。

这只是几何分流：阈值需根据原图尺寸和背景复杂度调整，不能保证LaMa对所有细区域的修补质量。

距离变换接口依据：[OpenCV官方说明](https://docs.opencv.org/4.x/d7/d1b/group__imgproc__misc.html)。
