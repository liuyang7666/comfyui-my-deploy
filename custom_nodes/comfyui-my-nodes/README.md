## 下拉选择

点击添加或修改，在弹窗中编辑短标题和对应的多行长文本。下拉只显示标题，文本输出为选中项的完整正文；选项和选择随工作流保存。

## 遮罩分流（宽度）

连接遮罩或MASK批次，设置原图像素下的宽度阈值（默认32）。每个独立连通区域按最粗处局部宽度整块分流：超过阈值进大遮罩，小于或等于阈值进小遮罩。小遮罩可接LaMa，大遮罩可接重绘。3像素细电线即使很长也按3像素宽度判断，弯曲细线也不按面积或外接框尺寸判断。

输出顺序为大遮罩、小遮罩，保留画布、批次顺序及原灰度软边，无目标的帧为全黑。相连的粗块与细枝作为整体；独立MASK批次逐张判断。羽化尾巴非零相连时视为同一区域，详情及测量精度见 `mask_router/README.md`。

## 移除路人（LaMa，遮罩驱动）

连接输入图像和遮罩；白色遮罩区域表示移除，黑色区域保留。节点通过 LaMa 做图像修补，**不自动识别人或生成遮罩**。`去除强度` 控制遮罩阈值，`边缘平滑` 控制边界过渡；模型可在执行后选择从显存卸载。

复用当前 ComfyUI 的 `models/RMBG/Lama/big-lama.pt`，无需复制模型权重；权重缺失时节点会从 `1038lab/Lama` 下载。代码通过 Python 文件流加载模型，保留了当前 Windows 中文安装路径的兼容修复。上游来源与 GPL-3.0 许可证见 `lama_remover/README.md` 和 `lama_remover/LICENSE`。

## 移除遮罩接缝

输入图像，以及遮罩或 XYWH 格式的边界框，设置接缝遮罩总宽度，输出沿遮罩边界分布的二值遮罩，可连接到 Lama 等修复节点。边界框可直接连接「遮罩裁剪（倍数）」的边界框输出；宽度为6时，区域向内收缩3像素并向外扩张3像素，再取扩张与收缩结果的差集。宽度为奇数时，向外扩张比向内收缩多1像素。图像与遮罩的宽高必须相同；单张遮罩或边界框可应用到图像批次。遮罩和边界框都连接时会先合并区域，再生成边界接缝。

## 遮罩裁剪（倍数）

保留 KJ 遮罩裁剪的选项和输出，并增加「倍数」整数输入。默认裁剪系数为3.000、BBox平滑透明度为0.50、倍数为16；可按需设置裁剪系数、平滑透明度，以及16、32或其他正整数倍数。

输出依次为原图像、裁剪图像、边界框、宽度和高度。边界框为原图坐标中的 XYWH；宽度和高度按倍数向上对齐。裁剪系数按遮罩范围扩展裁剪区域；平滑透明度按批次顺序平滑裁剪中心和尺寸，0会保持首张的中心和尺寸，1完全跟随当前遮罩。贴近原图边缘时，边界框会裁到图内，裁剪图像按目标尺寸缩放或以黑色补齐。空遮罩会报出清晰错误。
## 使用

安装文件夹名为 `MY`，放入当前实例的 `ComfyUI/custom_nodes/`，重启后端并刷新网页。在添加节点菜单的 `MY` 分类中查找。其他既有节点的 ID 与输入输出顺序保持不变，无需重新连接；像素漂移修复的两个网格变形参数已删除。

PixelDriftFix：原图接“原图（对齐基准）”，编辑图接“编辑后图像”。只保留全局透视对齐（整体位移、旋转、缩放、透视变化）。界面显示中文。

对齐必须有足够相同的画面特征。匹配失败会原样返回编辑图，并输出中文警告。内部按8位处理；画面边缘可能复制填充，不能保证纠正AI重绘的局部结构。保留 SIFT、暴力匹配、比值筛选及 RANSAC 算法与默认参数。

只有两图长边都超过 1536 像素时才在缩小副本上做特征检测与匹配，再按各自实际宽高和像素中心换算回原分辨率；只要有一边不超过 1536，就保留原尺寸检测路径。旧工作流里保存的 `method`/`max_mesh_points` 值会忽略，不影响已有连线。界面只保留两个图像输入，不再提供网格对齐。

对齐独立源码保存在工作区 `my-auto-align/`。打包脚本从此目录复制，禁止重新从上游生成旧版实现覆盖提速修复。运行日志分别显示检测、匹配和总耗时。

## 密钥和配置

API易继续读取当前用户 `APIYI_API_KEY` 与 `APIYI_ACCOUNT_TOKEN` 环境变量，配置文件在 `apiyi/config.json`。设置脚本为 `apiyi/配置密钥.ps1`。

## API易多模态聊天（识图）

节点 `APIYiVisionChat` 位于 `MY / API易`，可接入单张或批次 IMAGE，按提示词调用 API易视觉模型，输出文字回答和 token 用量。模型下拉包含 `gemini-3.8-flash`（日常推荐）、`gemini-3.5-flash-lite`（快速批量）、`gpt-6.1-sol`（复杂分析）、`gpt-6.1-terra`（视觉推理与性价比）、`gpt-6-luna`（低成本概述，细小 OCR 可能漏字）、`deepseek-v4-flash-vision-exp`（低图像 token）和 `qwen3.8-flash`（中文性价比）。API易侧可用型号以账号实时模型列表为准。

图片长边自动缩放至 2048 像素并以 Base64 传输，单次最多 16 张。节点不会自动重试；遇到超时或断连时先查 API易调用记录，确认状态后再决定是否重新运行。图片会发送至 API易服务。密钥读取 `APIYI_API_KEY`，API 地址复用 `APIYI_BASE_URL`。

千问继续使用已有 `%LOCALAPPDATA%/ComfyUI-QwenAPI/credentials.dpapi`，以及原有 `DASHSCOPE_API_KEY` 优先级，设置脚本在 `qwen/配置密钥.ps1`。合并不复制或解密密钥，不需要重新配置。

API易既有VIP重试、非VIP及官方备用、动态图片、蒙版、费用显示保留；分块和千问请求行为保留。API节点运行仍按原服务计费。

原三个已安装插件在迁移时移动到 `custom_nodes/.disabled/MY-migration-20261026/`，保留回滚副本。不能同时启用旧插件和MY，否则节点 ID 可能相互覆盖。升级或维护以MY目录为准。
