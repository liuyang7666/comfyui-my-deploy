# Image 2.5 自动分块 v2.1

末尾新增`分块图像`（IMAGE）输出：直接输出已补边、包含重叠的分块批次，按从上到下、从左到右的顺序排列；原九个数值输出的顺序和连接不变。可直接连接预览、保存或生成节点，不用再接一次分块。单图输出数量等于`数量`；输入批次按块优先排列，每块保留输入批次顺序。ImageUntile+仅支持单图的分块批次，多图输入需分别合成。

优先选择总块数最少的行列组合；数量相同时优先少补边，再接近3%重叠。自动在2%–4%内计算整数重叠，包含重叠后的每块宽高均为16倍数。不是只比较长边方向。

每块最长边≤3840，面积655360–8294400，长宽比≤3:1；允许任意符合这些官方限制的尺寸。输入已为16倍数时仍逐块满足此约束。2%–4%按现有ImageTile+的重叠/基础块语义计算；单行或单列在对应轴无重叠。旧overlap参数保留为偏好，自动适配到2%–4%，避免旧5%工作流失效。

输出接口不变：列、行、数量、右补齐、下补齐、重叠X、重叠Y、块宽、块高。ImagePadKJ使用edge_pixel补右/下；ImageTile+的overlap设0，overlap_x/y连接规划结果。ImageUntile+使用同一行列数和分块节点返回的重叠，最后从(0,0)裁回输入原宽高。分块和合成不缩放图像；不能把核心块取16倍数后再随意加重叠。

例：6000×4000→4块，7808×6000→6块，10000×6000→8块；12000×3008→5块，避免旧长边优先算法分成8块。最少数量范围为ImageTile+支持的每轴1–256块，使用2%重叠时可行就不会因3%偏好多分块。

三份子图已同步默认值、提示和参数。两份大图生成的OpenAI节点使用Custom尺寸，宽高读取实际输入块；原auto模式不会采用已连接的custom_width/height。原-6000入口缩放不变，恢复尺寸指进入分块器的输入尺寸。

验证：5000组16倍数随机尺寸、125组其他边长上限、独立枚举数量/因数组合的最少块数检查，以及13组当前桌面版Pad/Tile/Untile实际代码回环。未调用生成模型；数学回环不代表AI照片接缝视觉通过。外部API应按请求返回块尺寸，自动改尺寸的服务仍需核验实际输出。

更新后重启ComfyUI后端并重新加载子图；已打开画布的内嵌旧定义不会自动更新。
