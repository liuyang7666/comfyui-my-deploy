ComfyUI 中文自动补边节点（Qwen Image 2.1 使用）
================================================
安装：
1. 解压 ZIP，将 ComfyUI_PadToMultiple_CN 文件夹放到 ComfyUI/custom_nodes/ 中。
2. 如果你之前已安装 ComfyUI_PadToMultiple 文件夹，建议先删除旧文件夹，避免两个插件同时注册同一英文兼容节点。
3. 重启 ComfyUI，浏览器刷新页面。
4. 搜索节点“图像自动补边到指定倍数【全中文】”。

全中文接口：
输入图像：IMAGE，需要补边的裁剪图。
补边倍数：整数，默认 32。
补边模式：复制边缘（推荐）/镜像补边/补黑边。
输出：补边后图像 IMAGE。

算法：只在右侧和底部补边，不缩放人物、不修改左上角原像素。宽高分别向上取整到 32 的倍数。若尺寸已经合格则原样返回。
注意：此节点不保存原宽高。请在补边前用“获取图像尺寸”记录宽高，Qwen 生成后按原宽高裁掉补边，再按 SEGS 遮罩回贴。

兼容性：
新中文节点的内部标识为 PadImageToMultipleZH。
老工作流仍可使用原标识 PadImageToMultiple，输入和选项保持英文。
请不要单独修改 JSON 中的 type 或 name，应直接导入附带的中文工作流。
