# 对齐缩放与还原

两个无新增依赖的 ComfyUI 节点，搜索「对齐缩放」「对齐还原」，分类 `image/upscaling`。

## 连线

```text
待编辑图像 → 对齐缩放 → 编辑图像 → 对齐还原 → 保存图像
               对齐信息 ──────────↗
```

「对齐缩放」的 `long_edge` 输入 2048、1536、1024 或自定义整数，`short_multiple` 选 32 或 16。输出图像、**本节点输入时的宽和高**、对齐信息。前面节点已经裁剪/缩放的，就记录处理后的实际尺寸；不读取磁盘原图或 EXIF 宽高。

短边向上补齐，补边放在右侧或底部，使用边缘像素复制。长边固定、短边是指定倍数，图像内容始终按同一个比例重采样。没有把短边取整后的尺寸重新当作比例，避免横纵方向比例不一致。

自定义长边不是倍数且输入接近方形时，会先等比适配可用画布，并在长边末端也补少量边，确保输出长边不会被取整后的短边超过。例如方图指定1001、倍数32，画布为1001×992，内容为992×992。常用2048/1536/1024没有此特例。

例如 6000×4000，长边 2048、倍数 32：比例为 2048/6000，内容覆盖约 2048×1365.333 像素，输出画布 2048×1376。「对齐还原」按同一坐标映射回到 6000×4000，自动排除补边范围。竖图的补边在右侧。

**含补边的编辑图像必须接配套还原节点。** 宽高输出用于记录或其他计算；把整张补边图直接拉成这两个尺寸会造成变形。对齐信息直连还原节点，无需手填尺寸。

## 对齐的范围

- 缩放和还原均使用抗锯齿双三次、`align_corners=False`，固定像素中心公式：`编辑坐标 = (输入坐标 + 0.5) × 比例 − 0.5`。还原使用其逆映射，不重新计算取整后的短边比例。
- 编辑过程须保持画布尺寸、坐标与构图。尺寸改变会明确报错；同尺寸图中的裁剪、旋转或生成模型自行移动物体，节点无法自动识别和纠正。
- 「坐标对齐」不等于像素值无损。缩小会丢失细节，放大不能保证每个像素数值恢复；不保证AI输出的内容与原图逐像素重合。
- 支持同尺寸图像批次及 RGB/RGBA 浮点图像，不经过8位量化。FP16/BF16 在重采样时转为 FP32，随后恢复输入类型。
- 自定义长边仅保证短边是倍数；如模型要求两边都可整除，长边也请选择16/32倍数。

采样参数依据：[PyTorch interpolate 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.interpolate)。

## 安装

将整个 `comfyui-aligned-resize` 目录放到当前实例的 `custom_nodes`，重启 ComfyUI 后端，再刷新节点列表。不替换已有「分辨率选择」节点。

本机验证：使用当前 ComfyUI 的 Python 运行 `tests/test_alignment.py`。测试覆盖比例、奇数尺寸、横竖图、批次、坐标回环、编辑位置、补边、类型及尺寸改变拦截；不作为真实AI编辑效果验收。
