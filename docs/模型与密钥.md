## 密钥

- API易：在新机器设置 `APIYI_API_KEY`，需要余额/记录查询时再设置 `APIYI_ACCOUNT_TOKEN`；可选 `APIYI_BASE_URL`。
- 千问：设置 `DASHSCOPE_API_KEY`，或在 Windows 运行 `custom_nodes/comfyui-my-nodes/qwen/配置密钥.ps1` 重新保存本机凭据。
- 官方备用接口：在 ComfyUI 登录自己的账号，使用相应官方服务额度。

设置环境变量后重新启动 ComfyUI。不要把真实密钥填进要提交到 GitHub 的 JSON、截图或脚本。API 模块会将输入发送给所选服务，调用可能计费。
