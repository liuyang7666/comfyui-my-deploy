RMBG 3.2.0 和 TBG-SAM3 1.1.1 的已安装局部修改另存 `overlays/`。它们保留中文路径加载、模块导入及模型路径等本机修复，**部署脚本不会自动覆盖上游**。仅在安装相同版本、备份原文件并核对差异后手动合入；不要把其他版本文件整体覆盖。来源及许可证随对应目录保留。其他第三方插件的完整本地修改尚未逐文件归档，清单不等于整个实例的无损镜像。

照片加载器的 RAW EXIF 额外需要 ExifTool：从 [ExifTool 官网](https://exiftool.org/) 下载 Windows 发行包，将 `exiftool.exe` 及同包 `exiftool_files/` 放在 `custom_nodes/ComfyUI-zveroboy-photo/vendor/exiftool/`。仓库不包含可执行程序。

Darkroom 匹配模块还依赖 `comfyui-darkroom` 1.31.0 以及对应语义分割模型；纯数值接口通过不等于照片风格匹配已验收。

## 旧子图中额外引用但当前未注册的节点

- `Switch any [Crystools]`：`comfyui-crystools`，流程内版本 `1.27.4`。
- `RC_PreviewImageNoMetadata`：`kj863257/ComfyUI_RC_Image_Compositor`，流程内版本 `b9be8ef90121ad0f20cf7d9b8d7878a60a5cb989`。

这两类引用出现在「自动大图生成」旧子图中。需要保留旧图时再安装对应插件；当前快照不宣称这些旧图可直接执行。`Reroute (rgthree)` 属于前端重路由，无需出现在后端 object_info 中。
