# 节点清单

- `comfyui-my-nodes`：MY 整合节点（另含皮肤瑕疵模块快照）。
- `comfyui-aligned-resize`：长边缩放、16/32 对齐和坐标还原。
- `comfyui-concurrent-images`：分块并发提交和按序取回。
- `comfyui-resolution-select`：分辨率选择。
- `comfyui-darkroom-reference-match`：参考图颜色范围匹配 v0.5.0（实验）。
- `ComfyUI-zveroboy-photo`：本地照片/文件夹加载、EXIF 和保存。
- `ComfyUI_PadToMultiple_CN`：中文图像补边。
- `comfyui-apiyi-gpt`：并发模块所需的旧路径配置兼容入口；不注册节点。

MY 当前源码共包含 13 个节点 ID，包含 `MYSkinBlemish`；原 README 未列出该后加模块。该模块验证状态未登记，不按已验收功能推荐。节点注册现状可用 `scripts/check_runtime.py` 核对。

`archives/standalone/` 保存 API易、千问和分块的独立版本，仅供对照。MY 已提供对应节点，不要把这些目录整体再复制到 custom_nodes，否则同名 ID 会覆盖。
